# ClipRaft macOS 版移植计划

## 目标

在本仓库内迭代出 macOS 版本，功能对齐 Windows 版现有闭环：复制文本/图片/文件 → 捕获卡片（去重/固定/软删除/撤销）→ 小溪面板展示（WebGL 流体水面 + 三色木筏）→ 恢复/自动粘贴/拖出/拖入/垃圾区 → 历史保留开关 → 托盘常驻 + 右缘停靠 + 不抢焦点复制预览。Windows 代码保持原行为不破坏。

基于三路调研（clipboard-rs 0.3.5 源码、Tauri 2.11 源码、EcoPaste/Maccy/PasteBar 实现），关键结论：**clipboard-rs 0.3.5 在 macOS 全功能可用**（本机 Cargo.lock 已锁定 0.3.5）；Tauri 2.11.5 已具备所需全部 API；macOS 侧自动粘贴与拖出有成熟无权限/低权限方案。

## 关键技术决策

| 领域 | Windows 现状 | macOS 方案 |
|---|---|---|
| 剪贴板监听 | clipboard-rs 事件驱动 | clipboard-rs 0.3.5 `new_with_interval(120ms)` 的 changeCount 轮询（EcoPaste 验证值；Windows 忽略该参数，行为不变） |
| 无 Dock 图标 | `skipTaskbar` | `set_activation_policy(Accessory)`（setup 中调用） |
| 透明窗口 | `transparent: true` | 需 `app.macOSPrivateApi: true`（私有 API；本产品不上架 App Store，spec 允许） |
| 不抢焦点弹出（ADR-0002） | 直接 show | `set_focusable(false)` → `show()`；用户点击面板（`acceptFirstMouse: true`）或快捷键打开时 `set_focusable(true)` |
| 自动粘贴 | 记录 GetForegroundWindow → SetForegroundWindow → SendInput(Ctrl+V) | **不需要记录前台窗口**：面板从不激活前台 app；恢复时先隐藏面板（系统自动归还焦点）→ sleep ~80ms → CGEvent 注入 ⌘V（keycode 0x09 + COMMAND，post HID tap）。需辅助功能权限 |
| 拖出 | 轮询 GetAsyncKeyState+GetCursorPos，松手找窗口→点击→Ctrl+V | **原生 `beginDraggingSession`**（NSPasteboardItem + NSDraggingItem，EcoPaste Apache-2.0 实现思路）：无需任何权限，语义标准（文本/HTML/RTF/图片/文件）。行为差异：松手是把内容交付给目标 app（与所有 macOS 剪贴板管理器一致），不再模拟点击+粘贴 |
| 拖到垃圾区删除 | 轮询线程比较光标与垃圾区矩形 | 拖拽会话结束回调把落点发回前端（`drag://ended` 事件），前端判断是否落在垃圾区 |
| 快捷键 | F9（前端监听） | 引入 `tauri-plugin-global-shortcut`，注册 ⌥⌘V = 恢复并粘贴最新卡片（对齐 spec 的 Win+Alt+V）；F9 前端监听保留 |
| 权限检查 | 无 | `AXIsProcessTrusted()` 检查（直接 3 行 extern "C"，不引依赖）；未授权时自动降级为"仅复制"并在状态条提示，可调用 `AXIsProcessTrustedWithOptions(kAXTrustedCheckOptionPrompt=true)` 触发系统引导 |

自动粘贴失败规则遵循 spec：恢复剪贴板成功后即使注入失败也保留"内容已复制"结果。恢复时写入剪贴板的自回环由现有 `ignored_hashes` 机制抑制（跨平台通用）。macOS 写入 Html/Rtf 时补写纯文本孪生表示（clipboard-rs 0.3.0 的单 NSPasteboardItem 设计已保证，`set(vec![Text, Html])` 与现有代码一致）。

## 架构改动（文件级）

1. **平台边界拆分**（唯一一次重构，行为不变）：在 `src-tauri/src/` 新增 `platform/mod.rs`、`platform/windows.rs`、`platform/macos.rs`。迁入：前台窗口记录/恢复、paste 键注入、拖出监视器。深模块接口：`remember_paste_target()`、`paste_to_target()`、`start_drag_out(payload, app)`。`lib.rs` 其余部分（AppState、SqliteStore、capture、commands）保持平台无关不动，Windows 分支 `#[cfg(windows)]` 原样迁入。
2. **`platform/macos.rs`** 新增：
   - 辅助功能权限检查/引导（extern "C" AXIsProcessTrusted*）；
   - CGEvent ⌘V 注入（移植 EcoPaste `keystroke/macos.rs`，Apache-2.0，登记 THIRD_PARTY_NOTICES.md）；
   - 原生拖出（NSDraggingSession + NSDraggingSource，`run_on_main_thread` 执行；文件/图片用 PNG 快照 NSImage 预览，文本卡绘制简易预览），会话结束 emit 落点事件。
3. **窗口壳**：`tauri.conf.json` 加 `app.macOSPrivateApi`、窗口 `acceptFirstMouse`/`visibleOnAllWorkspaces`；`dock_window()` 改用 `monitor.work_area()`（Tauri 2.11.5 已含 macOS Y 修正；Windows 保留原全屏逻辑，cfg 区分）；`expand_window()` 的 focusable 舞步；托盘 `.icon_as_template(true)`（macOS 菜单栏适配）。
4. **前端**：`App.tsx` 增加 `focus_panel` invoke（面板点击时恢复可聚焦，供搜索框/键盘导航用）；拖出阈值触发后调用同一命令，macOS 由原生会话接管（ghost 保留至会话开始）；`App.css` 字体栈补 `-apple-system`/`PingFang SC`。
5. **Cargo.toml**：`[target.'cfg(target_os = "macos")'.dependencies]`：`core-graphics`、`objc2`、`objc2-app-kit`（按需 features）、`objc2-foundation`；加 `tauri-plugin-global-shortcut`。
6. **文档**：新增 `.scratch/macos-port/spec.md`（本计划的落地规格）、`docs/adr/0003-macos-port-platform-boundaries.md`（平台边界与权限模型决策）；更新 README.md（macOS 构建/权限/已知限制）、THIRD_PARTY_NOTICES.md（EcoPaste keystroke/drag-out 来源登记）。

## 验证

- 第 0 步：确认本机 node/npm/cargo 工具链，`npm install`。
- 每切片：`cargo test --manifest-path src-tauri/Cargo.toml`（现有测试全部平台无关）、`cargo check`（macOS 目标）、`npm run build`。
- 真机闭环（本机为 macOS）：`npm run tauri dev` → 复制文本/图片/文件捕获 → 去重/固定/删除/撤销 → 恢复到系统剪贴板 → 授予辅助功能权限后自动粘贴 → 拖出到 Notes/Finder/微信 → 拖入建卡 → 历史保留开关重启行为。**需要你手动在 系统设置→隐私与安全性→辅助功能 中授权 ClipRaft**，届时我会给出引导。
- 打包：`npm run tauri build` 产出 .app（icons 已含 icon.icns），双击验证托盘/停靠。

## 已知限制与风险（将写入文档）

- 原生窗口无法覆盖原生全屏 app 所在 space（Tauri tao 仅用 NSFloatingWindowLevel；如需覆盖，后续引入 tauri-nspanel，EcoPaste 同款方案，列为后续项）。
- 辅助功能权限是自动粘贴的硬门槛；未授权自动降级为仅复制，不丢内容。
- Tauri #15005：打包后 Dock 图标可能偶现（兜底 `set_dock_visibility(false)`）。
- 混合 DPI 多显示器定位有 Tauri 已知 bug（#7890）；MVP 单显示器不受影响。
- ⌘V 注入对非拉丁键盘布局沿用 keycode 0x09（Maccy 的 Dvorak-QWERTY 修正暂不做）。

## 不做

不改 Windows 现有行为；不引入状态管理/动画库/dnd-kit；不做多显示器设置 UI、云同步、OCR、遥测；不 push 远端；不改视觉稿与 `.impeccable` 素材。
